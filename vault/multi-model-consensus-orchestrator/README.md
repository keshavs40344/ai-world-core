# Multi-Model Consensus Orchestrator

Sovereign distributed consensus engine for multi-agent fleets. Detects hallucinations, measures semantic drift, and resolves quorum voting without external cloud API dependencies.

## Key Capabilities
- **Quorum Resolution**: Evaluates peer agreement across candidate model outputs.
- **Drift Detection**: Calculates token overlap variance to isolate aberrant responses.
- **Zero Cost**: Built entirely with Python 3.11+ standard library.
