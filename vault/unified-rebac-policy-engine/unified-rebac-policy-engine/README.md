# Unified ReBAC & ABAC Policy Engine

A high-throughput, sovereign authorization engine uniting Relationship-Based Access Control (ReBAC) and Attribute-Based Access Control (ABAC). Eliminates authorization ambiguity and vendor lock-in (e.g. costly external IAM SaaS).

## Features
- **ReBAC Graph Traversal**: Direct and hierarchical relationship lookups.
- **ABAC Contextual Rules**: Evaluates dynamic attributes (IP, time, security tier) on the fly.
- **Zero Latency**: Microsecond in-memory policy resolutions with zero external network overhead.
